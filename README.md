

# 📘 **Методика оценки техники движений в Virtual Coach**  
*Версия 2.0 | Разработано: Ermakov.AV, 2025*

---

## 1.  Назначение программы

**Virtual Coach** — это интеллектуальная система обратной связи для спортсменов и тренеров, позволяющая:

- ✅ **Сравнивать** выполнение упражнения с эталонной (модельной) техникой,  
- ✅ Получать **количественную оценку отклонений от эталонного выполнения** в процентах от 0 до 100%,  
- ✅ Визуализировать **отклонения по конкретным параметрам** (углы, скорости, ускорения и др.),  
- ✅ Получать **персонализированные рекомендации** по улучшению техники.

Программа подходит для:
- 🏸 Тенниса, гольфа, бейсбола (анализ замаха, удара),
- 🥋 Единоборств (удары и их комбинации, сложно координированные движения),
- 🏃 Бега, прыжков (фазы отталкивания, приземления),
- 🧘 Реабилитации и коррекции осанки.

>  **Главное преимущество**: объективная оценка без привязки к абсолютным нормам — только к *индивидуальному эталону*.

---

## 2.  Принцип работы

### 2.1. Входные данные

На вход поступают **два видеоряда**:

| Источник | Формат | Содержание |
|---------|--------|------------|
| **Модель** (эталон) | `model.mp4` + `model.csv` | Идеальное/оптимальное исполнение (от высококвалифицированного спортсмена, тренера) |
| **Пользователь** | Видео с камеры или файла | Повтор упражнения спортсменом |

Файл `*.csv` содержит **временные ряды** (по кадрам):
- Углы суставов:  
  `shoulder_left/right_angle`, `elbow_left/right_angle`, `hip_left/right_angle`, `knee_left/right_angle`, `x_factor_angle`  
- Производные величины:  
  `*_velocity`, `*_acceleration`, `*_entropy`  
  *(энтропия = мера стабильности траектории: чем ниже — тем повторяемость выше)*

---

### 2.2. Обработка видео

- Используется **MediaPipe Pose** для детекции 33 ключевых точек тела.
- Для каждого кадра рассчитываются:
  - Углы в 4 суставах (по 2 стороны): **плечо, локоть, таз, колено**  
  - **X-фактор** — угол между линией плеч и линией бёдер (ключевой параметр ротационных движений)  
  - Скорости и ускорения — численным дифференцированием  
  - Энтропия — по распределению значений за последние 30 кадров (окно скольжения)

> ⚠️ Кадры с низкой достоверностью (`visibility < 0.5`) автоматически исключаются из анализа.

---

## 3. Алгоритм оценки совпадения

Оценка производится **по 36 временным рядам** и построена на **иерархической взвешенной агрегации**:

### 3.1. Этап 1: Нормированное сравнение каждого ряда

Для каждого параметра (например, `shoulder_left_angle`) вычисляется **нормированный DTW**:

$$DTW norm = DTW(A,B)/(σA*N)$$
 
где:  
- `(A, B)` — интерполированные временные ряды модели и пользователя (единая длина ~60 точек),  
- `(sigma_A)` — стандартное отклонение ряда модели (мера «динамичности» движения),  
- `(N)` — длина интерполированного ряда.

✅ **Преимущества DTW**:
- Устойчив к временному сдвигу (пользователь начал чуть позже),
- Учитывает локальные ускорения/замедления,
- Корректно работает при различной длительности видео.

На основе DTW формируется **рейтинг отклонений**: выбираются **ТОП-3 параметра с наибольшим нормированным DTW**.

---

### 3.2. Этап 2: Группировка и оценка

Все 36 параметров объединены в 5 групп:

| Группа | Параметры | Вес |
|--------|-----------|-----|
| **Ключевые углы** | `shoulder_L/R`, `x_factor_angle` | **40%** |
| **Остальные углы** | `elbow`, `hip`, `knee` | **25%** |
| **Скорости** | Все `*_velocity` | **15%** |
| **Ускорения** | Все `*_acceleration` | **10%** |
| **Энтропии** | Все `*_entropy` | **10%** |

- Внутри группы — средневзвешенное (X-фактор имеет повышенный вес: ×1.5).
- Итоговая оценка является средневзвешенной оценкой суммы всех параметров 



### 3.3. Пример расчёта (на ваших данных: `data_1766228186.csv`)

| Группа | Оценка | Вклад в итог |
|--------|--------|--------------|
| Ключевые углы | 39.4% | 0.40 × 39.4 = **15.8%** |
| Остальные углы | 26.4% | 0.25 × 26.4 = **6.6%** |
| Скорости | 44.7% | 0.15 × 44.7 = **6.7%** |
| Ускорения | 44.2% | 0.10 × 44.2 = **4.4%** |
| Энтропии | 44.1% | 0.10 × 44.1 = **4.4%** |
| **Итого** | — | **37.9%** |

>  Несмотря на «высокие» 44% по скоростям — общий результат низкий, потому что **углы (ключевая группа)** плохо совпадают.

Отчёт (`report_*.pdf`) включает:

|--------|--------|-----|
| Ключевые углы (плечи, X-фактор) | 39.4% | 0.40 |
| Остальные углы (локти, таз, колени) | 26.4% | 0.25 |
| … | … | … |

### 4.3. Графики (6 отдельных, по 1 параметру на график)
- ✅ `X-фактор (угол)`  
- ✅ `Левое плечо (угол)`  
- ✅ `Правое плечо (угол)`

- **Модель** — сплошная линия, **голубой** (`#2196F3`)

### 4.4. Персонализированные рекомендации

❗ **Указывают на конкретные отклонения от модельных значений**  
Алгоритм **всегда** отбирает **ТОП-3 параметра с наибольшим отклонением по нормированному DTW** и даёт конкретные указания:

> 🔹 **1. X-фактор (скорость)**: Скорость выполнения не совпадает с моделью: возможен слишком резкий старт или «просадка» в середине фазы.  
> 🔹 **2. Левое плечо (угол)**: Обратите внимание на амплитуду и форму движения в ключевые фазы.  
> 🔹 **3. Правое плечо (скорость)**: Движение нестабильно: повторяемость траектории низкая — уделите внимание контролю.

## 5.  Кому и как использовать

### Для тренеров:
- Загрузите **требуемое исполнение** как `model/`,  
- Пусть спортсмен выполняет упражнение в режиме **Camera**,  
- Получите **объективный отчёт** — без субъективной оценки «почти как у модели».

### Для спортсменов (самостоятельно):
- Снимите своё исполнение → сверьтесь с моделью,  
- Сфокусируйтесь на **3 рекомендациях** — это даёт **максимум прогресса при минимуме усилий**.

### Для реабилитологов:
- Используйте **энтропию** как меру стабильности:  
  - ↓ энтропия = ↑ повторяемость

## 7.  Пример использования (пошагово)

1. Создайте папку `model/`, положите туда:  
   - `model.mp4` — эталонное видео,  
   - `model.csv` — соответствующие временные ряды (из MotionAnalyzer).  
2. Запустите `VirtualCoach.exe`.  
3. Нажмите **📁 Загрузить модель** → выберите папку `model`.  
4. Нажмите **📹 Камера** → встаньте в зону видимости.  
5. Нажмите **▶️ Начать**:  
   - слева — модель,  
   - справа — вы в реальном времени.  
6. По окончании:  
   - на экране — **крупный % + цветные бары согласно оцениваемым группам параметров**,  
   - в папке `coach_output/` — PDF-отчёт, сырые данные  CSV и аннотированное видео.  
7. Откройте PDF → изучите **ТОП-3 рекомендации** → тренируйтесь с фокусом на них.

---

## 8.  Важные ограничения

- ❗ Работает корректно для **фигур человека полный рост** (все суставы в кадре),  
- ❗ Не учитывает силу/нагрузку — только **кинематику**,  
- ❗ Требует качественного эталона: если модель «плохая» — отчёт будет смещён.
